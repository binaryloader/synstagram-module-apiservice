# synstagram-module-apiservice

Synstagram iOS 앱을 위한 API 서비스 모듈이며 CocoaPods pod 형태로 배포한다.

## 모듈

### Auth

로그인과 로그아웃 모델, 네트워크 타깃, 서비스 레이어를 포함한 인증 서비스를 제공한다.

## 의존성

- BinaryLoaderExtensions 1.0.3
- BinaryLoaderNetwork 1.0.5

## 설치

비공개 spec repo와 pod를 `Podfile`에 추가한다.

```ruby
source 'https://github.com/binaryloader/synstagram-module-cocoapods-specs.git'

pod 'APIService/Auth'
```
